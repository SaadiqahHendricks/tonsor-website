# TONSOR Barbershop — revised homepage

This version shifts the visual direction toward bold, modern urban barber culture.

## Included
- `index.html` — homepage structure and content
- `css/style.css` — responsive styling, animations and hover effects
- `js/main.js` — mobile navigation, scroll reveals and subtle button movement
- `assets/tonsor-logo.png` — original supplied logo
- `assets/tonsor-logo-cropped.jpg` — tighter crop for the larger header mark

## Run locally
1. Extract the ZIP.
2. Open this folder in Visual Studio Code.
3. Open `index.html` with Live Server (recommended), or open it directly in a browser.

## Notes
- The hero image is currently loaded from Unsplash; replace it with a photo you have permission to use before publishing.
- The booking button is an email-enquiry placeholder. The real availability and booking-request workflow is not connected yet.
- Replace sample contact details and add the real address, prices, service durations and opening hours later.
